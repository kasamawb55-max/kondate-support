# Kondate サポート

「Kondate - AI献立・夕飯決め」をご利用いただきありがとうございます。

Kondateは、毎日の献立決めをサポートするiPhone向けアプリです。
AIシェフによる献立提案、レシピ、買い物リスト、冷蔵庫の食材管理などの機能を提供しています。

## お問い合わせ

アプリに関するご質問、不具合、ご要望などがございましたら、以下のメールアドレスまでお問い合わせください。

**kondate.jp@gmail.com**

お問い合わせの際は、可能であれば以下の情報をご記載ください。

- ご利用のiPhone機種
- iOSのバージョン
- 発生した問題の内容
- 問題が発生した画面や操作
- スクリーンショット（可能な場合）

## Premiumについて

Kondate Premiumでは、1週間の献立作成やまとめ買いリスト、家族や冷蔵庫の食材を考慮した献立提案などの追加機能をご利用いただけます。

購入や復元に問題がある場合は、アプリ内の「購入を復元」をお試しください。

解決しない場合は、上記メールアドレスまでお問い合わせください。

## AIシェフについて

AIシェフによる回答や献立提案は、入力された情報などをもとに生成されます。
生成された内容は参考情報としてご利用いただき、食物アレルギー、食材の安全性、健康に関する重要な判断については、必ずご自身でもご確認ください。
